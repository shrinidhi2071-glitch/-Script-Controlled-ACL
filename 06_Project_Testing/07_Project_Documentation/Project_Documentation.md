# Project Documentation

## Project Title

**Script-Controlled ACL – Restrict Record Access Based on Field Value**

## Technology Used

- ServiceNow
- Access Control Lists (ACL)
- JavaScript
- ServiceNow Roles
- Custom Tables

## Project Objective

The objective of this project is to implement record-level security in ServiceNow using ACLs and scripts.

The project demonstrates how different operations can be controlled using separate roles and how READ access can be restricted based on a field value.

## Key Features

- Custom user creation
- Custom role creation
- Custom table creation
- Field-based READ restriction
- Role-based CREATE permission
- Role-based WRITE permission
- Role-based DELETE permission
- Administrator full access

## Access Control Structure

| Operation | Role |
|---|---|
| READ | `bb1` |
| CREATE | `bb2` |
| WRITE | `bb3` |
| DELETE | `bb4` |
| Full Access | `admin` |

## Project Outcome

The project successfully demonstrates how ServiceNow ACLs can be used to control access to records based on user roles and field values.

The implementation provides controlled access to Institution Details records and helps improve record-level security.
