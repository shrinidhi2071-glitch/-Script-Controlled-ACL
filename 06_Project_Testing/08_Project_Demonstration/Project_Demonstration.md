# Project Demonstration

## Demonstration Overview

The project demonstration video explains the complete implementation of the **Script-Controlled ACL – Restrict Record Access Based on Field Value** project.

## Demonstration Steps

The video demonstrates:

1. ServiceNow login.
2. Creation of the EEE User.
3. Creation of custom roles.
4. Creation of the Institution Details table.
5. Creation of table fields.
6. Creation of sample records.
7. Configuration of READ ACL.
8. Configuration of CREATE ACL.
9. Configuration of WRITE ACL.
10. Configuration of DELETE ACL.
11. Testing access using different roles.
12. Testing administrator access.
13. Showing the final project outcome.

## Project Outcome

The project demonstrates the successful implementation of **role-based and field-based record access control** in ServiceNow.

Different roles are used to control READ, CREATE, WRITE, and DELETE operations, while the READ ACL uses a field condition to restrict access to EEE branch records.
